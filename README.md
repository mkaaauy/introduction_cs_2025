### Web-разработка (HTML, CSS, JavaScript)

#### Как открыть веб-страницу:

1. **Способ 1: Прямое открытие**
   - Откройте файл `index.html` в любом веб-браузере (Chrome, Firefox, Edge, Safari)
   - Просто дважды кликните на файл `index.html`

2. **Способ 2: Локальный сервер (рекомендуется)**
   ```bash
   # С помощью Python 3
   python3 -m http.server 8080
   # Затем откройте http://localhost:8080 в браузере
   ```

#### Структура проекта:
```
├── index.html      # Главная страница (HTML)
├── styles.css      # Стили оформления (CSS)
└── script.js       # Интерактивность (JavaScript)
```

#### Функции веб-страницы:
- 🎨 Изменение цвета фона (6 различных градиентов)
- 🔢 Интерактивный счётчик кликов с сообщениями
- 📱 Адаптивный дизайн (работает на мобильных устройствах)
- ✨ Плавные анимации и переходы
- 📝 Образовательный контент о веб-технологиях
